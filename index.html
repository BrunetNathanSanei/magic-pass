Une question ?

Validité 
La validité du Magic Pass 26/27 est fixe et annuelle : du 01.05.2026 au 30.04.2027.

Carte défectueuse
Nous vous invitons à vous rendre au guichet de nos stations partenaires afin qu'ils puissent vérifier l'état de votre Magic Pass.
S'il s'avère défectueux (sans dégât causé intentionnellement) votre carte sera changée sans frais.

SwissPass comptatible ?
Les supports de données que nous utilisons pour le Magic Pass sont des cartes à usage unique qui ne sont pas transférables sur le SwissPass ou tout autre support.

De manière générale : seule la carte physique Magic Pass 26/27 donne accès aux prestations incluses.

Velo

Le transport des vélos est inclus gratuitement dans le Magic Pass. Il est obligatoire de présenter la carte Magic Pass pour bénéficier des prestations liées. Une confirmation de commande, de paiement, ou une photo de la carte, par exemple, ne suffisent pas.

Chien

Les chiens ne sont pas inclus dans le Magic Pass. La tarification pour leur transport dépend de chaque station. Il est donc recommandé de se renseigner directement auprès de la station concernée.

Le forfait Magic Pass 26/27 n'est pas disponible pour les enfants de moins de 6 ans révolus. Il est nécessaire de se rendre aux guichets des stations pour obtenir un titre de transport valide pour les jeunes enfants. Il est à noter que les stations partenaires ont la liberté de fixer un tarif pour cette catégorie d'âge.

Pour la saison 26/27, sont considérés « enfants payants », les jeunes nés entre 2011 et 2020.
Dès l'âge de 16 ans (l'année de naissance fait foi), les tarifs évoluent au prix adulte.

Seules les catégories Magic Pass "adulte" et "enfant" sont disponibles (aucune autre réduction n'existe).

Moyen de paiement
Seuls les paiements par carte de crédit (MasterCard, Visa et American Express) REKA Pay, REKA Rail ou TWINT sont possibles.

- Vous avez également la possibilité de choisir le paiement échelonné avec HeyLight (jusqu'au 8 septembre 2026). En Suisse, ce mode de règlement est uniquement disponible pour les achats inférieurs à CHF 500. Si vous souhaitez commander plusieurs Magic Pass avec le paiement échelonné, il est nécessaire de passer des commandes individuelles. L'option bains peut être ajoutée ultérieurement. 

Confirmation de commande
Pour recevoir votre confirmation de commande, veuillez cliquer sur le lien reçu automatiquement par mail. Il vous permettra de télécharger votre preuve d’achat en version PDF. Si vous n’avez pas reçu de mail, veuillez vérifier vos « spams ».
La confirmation de commande seule ne donne pas accès aux installations des stations partenaires, mais uniquement la carte physique Magic Pass 26/27.

Numéro MP / Données sur le Magic Pass
Si vous ne connaissez pas votre numéro MP, vous pouvez indiquer votre prénom, votre nom et votre date de naissance et le système créera automatiquement le lien avec le numéro MP existant.

Délai de livraison Magic Pass
Pour les forfaits Magic Pass commandés avant le 17 avril 2026 : fin avril 2026
Pour les forfaits Magic Pass commandés après le 17 avril 2026 : En Suisse - votre commande sera traitée dans un délai de 2 jours ouvrables et livrée dans les meilleurs délais. 
Les envois à l'étranger dépendent des délais de livraison des services postaux.

Si vous n'avez pas reçu votre Magic Pass par la poste, veuillez nous en informer dans un délai de 3 mois après votre commande ; passé ce délai, un duplicata devra être commandé moyennant des frais de CHF 40.-.
